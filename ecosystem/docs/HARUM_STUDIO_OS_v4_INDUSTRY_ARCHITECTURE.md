# INDUSTRY ARCHITECTURE — v4

## O que foi assimilado da indústria

- **OpenCue**: jobs/layers/frames, resource scheduling, render nodes, monitoramento e arquitetura de render farm de produção.
- **OpenAssetIO**: ativos por identidade sem amarrar a pipeline a caminhos de arquivos.
- **OpenTimelineIO**: editorial como dados, não como arquivo de vídeo.
- **OpenUSD**: composição não destrutiva e layers para o futuro 3D/previs/virtual production.
- **MaterialX**: materiais/lookdev interoperáveis quando o ecossistema entrar em 3D.
- **OpenColorIO/ACES**: cor consistente entre engines.
- **AYON/Kitsu**: produção, publishing, review, tasks, sequences, shots e automação de workflow.
- **Ray**: scheduling distribuído em nós autorizados.
- **OpenCue** fica como opção de crescimento quando existirem máquinas suficientes para justificar uma render farm real.

## Filosofia Harum

A indústria grande separa:
1. criatividade;
2. produção;
3. computação;
4. editorial;
5. revisão;
6. dados;
7. distribuição.

O v4 faz o mesmo em miniatura — sem exigir infraestrutura paga para começar.
