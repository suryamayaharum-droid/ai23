# HARUM — Integration Map

## 1. Fonte canônica
`CONTEXTO_MESTRE_ARTE_HARUM.md` + `HARUM_NOIR_BIBLIA_CANONICA.md`.

## 2. Identidade visual
`assets/harum-noir/identity/` define referência fixa. Todo vídeo ou imagem oficial passa pelo gate de consistência.

## 3. Narrativa
Calendário, arcos, captions, commerce map e publication pack alimentam o briefing editorial.

## 4. Produção audiovisual
`cinebrain.py` cria o plano; `harum_router.py` escolhe rota; engines executam; `harum_review.py` e QC validam; `harum_edit.py` monta; `harum_audio_master.py` fecha áudio.

## 5. Produtos
PDFs ficam em `ecosystem/products-pdf/`. O commerce map conecta cada produto a um arco narrativo sem alterar autoria ou afirmar disponibilidade antes da validação.

## 6. Distribuição
Instagram/YouTube/Studio 23 só recebem assets após gates de identidade, verdade, licença, QC e revisão humana quando aplicável.

## 7. Estado
GitHub = código, manifests e arquivo versionado.
Biblioteca = mestres canônicos e mídia.
Airtable = fila/estado/métricas quando conectado.
Hotmart = entrega/venda somente depois de elegibilidade e checkout validados.
