# ECOSYSTEM INTEGRATION v2 — SWARM CITY

Swarm City becomes the coordination layer across HARUM NOIR without replacing the specialized systems already present.

## Flow
`Brief / Bíblia / Face Lock → Swarm City → domain specialist → worker → QC/Governance → Archive → Distribution → Metrics/Memory`

## Cross-system links
- Atelier ↔ visual archive ↔ Tattoo Studio 23.
- Noir Editorial ↔ canonical bible/engine ↔ Cinema ↔ channels.
- Cinema ↔ CineBrain ↔ Compute Router ↔ Review/Edit/Audio.
- Products ↔ PDFs ↔ Commerce Guard ↔ Hotmart after validation.
- Distribution ↔ site ↔ SEO ↔ GitHub ↔ authorized channels.
- Memory & Archive ↔ library ↔ manifests ↔ hashes ↔ retrieval.
- Governance crosses every district and can block release.

## Evolution rule
Add a capability before adding a persistent agent. Create a permanent agent only for a recurring function no existing agent covers. Use ephemeral subagents for temporary load.
