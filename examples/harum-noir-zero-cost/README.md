# Harum Noir — Zero Cost Video Lab

Pipeline gratuito para o ecossistema Arte Harum / Harum Noir.

## Rotas
- **NoirMotion / FFmpeg:** anima stills em 9:16, sem GPU.
- **Piper pt-BR:** voz local gratuita.
- **LivePortrait:** close e microexpressão preservando o FACE LOCK.
- **LTX-Video 2B distilled:** image-to-video no Colab quando houver GPU.
- **YouTube Data API:** uploader opcional via OAuth.

## Regra
FACE > CABELO > ROUPA > PALETA > MOVIMENTO > VOZ > VERDADE > NOVIDADE.

O Colab gratuito não garante GPU; por isso o fallback FFmpeg é obrigatório.
