# HARUM / HARUM NOIR — Visual Archive

Acervo visual organizado do ecossistema Arte Harum / HARUM NOIR.

## Estrutura

- `assets/harum-noir/identity/` — referências canônicas, rosto/personagem e identidade.
- `assets/harum-noir/charcoal/` — estudos, retratos, modelo vivo, mãos e desenho a carvão.
- `assets/harum-noir/editorial/` — peças de narrativa, stories, calendário e colagens.
- `assets/harum-noir/tattoo/` — estudos e composições voltadas a tatuagem.
- `assets/harum-noir/collections/` — séries temáticas e coleções.
- `assets/harum-noir/raw/` — gerações brutas preservadas para curadoria futura.

Este branch (`harum-archive`) é dedicado ao acervo visual e fica separado do código principal do repositório.
