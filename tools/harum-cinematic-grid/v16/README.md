# HARUM Nervous System v16

Canonical default for the Arte Harum distributed organism.

## Default stack
Ouroboros gated self-improvement + HoloBus anti-entropy + Event Horizon durable workflows + CPU Mesh + SHA-256 CAS + Quantized Brain hook + Browser/WASM Seed + store-carry-forward capsules.

## Network rule
The application state is above the carrier. Local files, LAN, Reticulum, libp2p, Iroh, GNUnet, SCION, Syncthing, IPFS, Tor/I2P configured peers, and future transports are replaceable adapters.

## Space rule
Space is a public sensing plane. SatNOGS and CelesTrak are read-only sources. No spacecraft command/control, uplink, credential guessing or operator bypass is included.

## Self-improvement rule
Only measured mutations to prompts, routing, retrieval, cache and adapter preferences may be automatically promoted. Promotion requires held-out tests, rollback and hard gates.

## Patent rule
Generic open standards and independently designed primitives are preferred. Claim-specific CRDT, mesh, satellite-DTN and fountain-code mechanisms remain on the patent watch list until reviewed.
