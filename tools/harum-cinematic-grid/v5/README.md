# HARUM CINEMATIC FUSION v5

Zero-extra-cost control plane for the Harum Noir cinematic ecosystem.

Core graph:
Narrative -> Image -> Motion -> Control -> Audio -> Editorial -> QC/Color -> Distribution -> Learning

Principles:
- one scene is decomposed into short shots;
- each shot is routed by capability, available VRAM, license gate and zero-extra-cost policy;
- no quota evasion, no multi-account pooling, no watermark bypass;
- identity is preserved by canonical references; generation is used only where it adds value;
- deterministic CPU post is preferred whenever it can replace neural generation.

Primary free/permissive fronts:
- Images: FLUX.2 Klein 4B; Qwen-Image/Edit
- Video: Wan 2.2
- Music: ACE-Step 1.5
- Masks: SAM 2
- Editorial: FFmpeg + OpenTimelineIO + OpenColorIO/ACES
- Compute: Kaggle T4x2, Hugging Face ZeroGPU bursts, Colab interactive, GitHub Actions CPU/CI

See the persistent Harum Library package: /HARUM NOIR/HARUM_CINEMATIC_ECOSYSTEM_v5.zip
