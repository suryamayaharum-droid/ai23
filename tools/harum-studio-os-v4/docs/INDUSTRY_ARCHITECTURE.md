# Industry architecture

Assimilated standards and systems:
- OpenCue: production-proven render management, job/layer/frame scheduling and monitoring.
- OpenAssetIO: asset identity instead of fragile file-path coupling.
- OpenTimelineIO: editorial cut data as interoperable timeline metadata.
- OpenUSD: layered, non-destructive scene composition for future 3D/previs/virtual production.
- MaterialX: interoperable look/material descriptions.
- OpenColorIO/ACES: color-management backbone.
- AYON/Kitsu: publishing, review, tasks, sequences, shots and production tracking.
- Ray: authorized self-hosted distributed task scheduling.

Harum v4 starts lightweight and can adopt these systems only when scale justifies them.
