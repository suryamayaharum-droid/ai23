# HARUM NOIR — Free Video Lab

Pipeline sem assinatura para vídeos verticais da Harum Noir.

## Modos
- CPU Motion: imagem canônica → vídeo 9:16 com movimento cinematográfico via FFmpeg. Sempre disponível; preserva o FACE LOCK.
- LivePortrait: close/fala/microexpressão em GPU gratuita (Colab/Kaggle).
- LTX-Video: image-to-video open source quando houver GPU gratuita.
- Wan 2.1/VACE: movimento corporal quando houver GPU suficiente.

Saída padrão: 1080x1920, H.264, 30 fps, sem watermark.

Gate: FACE > CABELO > ROUPA > PALETA > MOVIMENTO > VOZ > VERDADE > CTA.
